## Priority ranking for the next phase (recommendation)

1. **CI/CD** (Bloc 12) — currently nothing gates merges; this is the highest-leverage, lowest-risk next investment.
2. **Permission Engine redesign** (Bloc 6) — needed before any CVLN system can safely be granted scoped access to FREKCORE identities.
3. **Event Bus implementation** (Bloc 7) — the catalog now exists (this session); wiring real producers (`identity_engine`, `fk`, `notary`) to emit the envelope is the natural next step.
4. **SDKs** (Bloc 9) — needed once external CVLN systems start consuming the Registry/Identity/Proof APIs documented in `docs/interfaces/`.
5. **Observability** (Bloc 11) — request-ID + Prometheus, additive and low-risk.

None of these five were implemented in this session; they are recorded here so the next pass starts from evidence, not from the Master Prompt's aspirational description.
